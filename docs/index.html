Steam, sail and iron on a living sea

EST. 1871

Ironwake is a peaceful-first steampunk naval game. Take a turret ironclad, a rigged brig or a paddle steamer between three working harbours, trade cargo with the harbourmaster, and watch a sea that behaves like water: crests by sea state, wakes from a solved Kelvin pattern, ships that heel and pitch.

Three harbours, each its own place

Ports are data, not hand-placed scenes: one JSON file sets each harbour's position, breakwaters, quays, berths and market. Make fast at the harbourmaster (Enter under 2.5 knots) to trade eight goods for Silver Crowns, then log the call in the captain's book (O).

The wake lab

Ship wakes in Ironwake come from a physics solve, not a texture of foam. A cluster job integrated the Havelock wave spectrum over 1,600 wave angles to get the Kelvin pattern at three Froude numbers, and built a turbulent twin-screw wash field. The game blends those tables by speed. This canvas runs the same blend on the real tables, live.

How it was built

Ironwake is also a research project: how far can an agent pipeline take a complex 3D simulation when a person sets direction and quality bars, and agents do the building, testing and art passes?

The loop

  1. A card per changeEach feature is a written card with a target, such as "town reads 7/10 from 400 m", on a Kanban board. A build agent works one card at a time.
  2. Heavy work on a cluster3D generation, wake physics, mesh prep and video encoding run as batch jobs on an HPC cluster, so the laptop stays free.
  3. Off-screen testsEvery run is headless and silent: fixed camera shots, multi-seed traffic soaks, paired FPS benchmarks.
  4. Scored, then promotedShots are scored by a vision reviewer against the card's target. A build replaces the playable app only after an independent verification card passes.
  5. A spec that cites the codeThe spec quotes every value with its source file and line, and a checker confirms all 3,658 citations still match.

The last overnight run

  1. P24Town at 400 m. Hillside terrain, landmark buildings, retaining walls.
  2. P25Quay lanes. Harbour-mouth lock and berth reservations: 0 collisions, 0 stuck, 0 groundings over three 50-minute seeds.
  3. P26The brig. 42 m Curlew with 17 moving rig parts; four-ship shipyard.
  4. P27Wakes. Havelock Kelvin and screw-wash tables solved on the cluster.
  5. P28Moving parts. 120+ animated parts: rowing crew, paddle wheels, crane and bell, airship screws.
  6. P29Two more ports. Ironcrag and Stigsby, three-port chart, market and logbook.
  7. P30Verify and promote. Multi-seed soak, paired FPS, spec check 3658 / 3658.

Run it yourself

You need Unreal Engine 5.8 (Water, Landmass and Python plugins ship with it) and a Mac with Apple Silicon or a Windows PC. Licensed third-party meshes and textures aren't in this repo. The C++, Python build scripts, data, spec and pipeline are all here; see CREDITS.md for asset sources.

Build and test

git clone https://github.com/charles-forsyth/ironwake.git
cd ironwake

# open IronwakeTest.uproject in UE 5.8 and build,
# or headless:
UnrealEditor IronwakeTest.uproject \
  -RenderOffScreen -nosound -unattended -nosplash

# check every spec citation against the source
python3 tools/spec_check.py --all

Combat exists in the code but is parked; this is a sailing game first. The open-sea storm look is parked too.
