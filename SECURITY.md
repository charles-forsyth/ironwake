# Security Policy

## Scope

Ironwake is a single-player, local-only Unreal Engine 5.8 maritime simulation and static browser showcase (`docs/`). Neither the C++ game client nor the GitHub Pages WebGL/audio showcase runs a backend server, accepts user authentication, stores credentials, or makes runtime network API calls.

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.0.x` (`main`) | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in the source code, build tooling, or GitHub Pages showcase, please report it privately via **[GitHub Private Vulnerability Reporting](https://github.com/charles-forsyth/ironwake/security/advisories/new)** rather than opening a public issue.
